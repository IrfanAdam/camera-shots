deviation Computed value departs from the token named in its row; the cite under it is the line to fix. Wiki dark is measured on the same pass and reported in the wiki note where it differs.

Every cell above is a computed value from the shipped pages at a 1440 viewport, printed at render. Where a surface departs from the token the badge and the file:line are generated from the same measurement, so the worklist cannot drift from the CSS. A cell that reads “none in DOM” means the surface ships no such element — not that it was skipped.

07

Component specimens

— blocks · — theme wrappers · — static states

The shipped library, drawn once per theme map in tokens.css: only data-ds-theme changes between the four cells, so a role token that fails to resolve shows as a hole. Rest, hover, focus and disabled are static [data-state] cells on real controls, so Tab reaches them. components.js is loaded with data-ds-manual.
