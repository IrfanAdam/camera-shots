07

Component specimens

— blocks · — theme wrappers · — static states

The shipped library, rendered rather than described. Every block is drawn once per theme map in tokens.css: the only thing that changes between the four cells is data-ds-theme, so a role token that fails to resolve shows up as a hole instead of a caption. Rest, hover, focus and disabled are static [data-state] cells where the CSS has that hook, and the same elements are real controls, so Tab reaches them. The page keeps its own light/dark theme — only these wrappers carry a theme map. components.js is loaded with data-ds-manual so the specimens stay exactly as authored.
